Autoclave prêt

Déposez une fiche (PDF ou DOCX) pour lancer un cycle : elle est convertie en Markdown par Docling, puis les identifiants sont repérés par eds-pseudo et des règles complémentaires.

Vous corrigez ensuite à la souris : sélectionnez un passage encore identifiant pour le masquer, cliquez sur une détection pour la corriger. Chaque correction enrichit le lexique local et améliore les documents suivants.
